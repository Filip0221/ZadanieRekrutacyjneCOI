# Zadanie rekrutacyjne COI - Filip Skup
Zadanie polegało na stworzeniu prostej aplikacji, która pobiera dane z publiczengo API (https://rickandmortyapi.com/documentation#rest) oraz zaprezentuje je użytkownikowi.

## Funkcjonalności

- Lista bohaterów z paginacją (infinite scroll)
- Wyszukiwanie bohaterów po nazwie
- Odświeżanie listy (pull to refresh)
- Widok szczegółów bohatera
- Widok szczegółów odcinka
- Lista bohaterów występujących w danym odcinku
- Możliwość dodania bohatera do ulubionych (zapisywane lokalnie)
- Obsługa stanów

## Technologie
- Swift 6
- iOS 18+
- SwiftUI
- The Composable Architecture
- Swift Concurrency 
- SwiftData 
- Swift Testing
- SnapshotTesting

## Dodatkowe elementy

- Obsługa ulubionych bohaterów (SwiftData)
- Sortowanie bohaterów (ulubieni na górze listy)
